# Application Documentation

## System Requirements

Before running the application, make sure your system meets the following requirements:
- **Operating System**: Windows 10/11, macOS, Linux
- **Node.js**: version 18.x or later
- **NPM** (or **Yarn** as an alternative)
- **Expo CLI**

## Setting Up the Environment

### 1. Installing Node.js
Download and install the latest version of **Node.js** from the official website:
[https://nodejs.org/](https://nodejs.org/)

After installation, check the versions of Node.js and NPM:
```sh
node -v
npm -v
```

### 2. Installing Expo CLI
Install Expo CLI globally:
```sh
npm install -g expo-cli
```

Verify the installation:
```sh
expo --version
```

## Downloading and Running the Application

### 1. Installing Dependencies
Run the following command in the project directory:
```sh
npm install
```

### 2. Running the Application
To run the application in developer mode:
```sh
npx expo start
```

Once it starts, you’ll see the Expo Developer Tools interface. You can run the app:
- **On an emulator/simulator** (if configured)
- **On a mobile device** using the Expo Go app (Android/iOS)
